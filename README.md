# ⚡ Electricity Bill Bot

### Telegram Bot | Automation | Web Scraping

> A simple, efficient Telegram bot to fetch and track electricity bills instantly.

---

## 📖 About the Project

Checking electricity bills shouldn't require navigating slow websites or downloading heavy apps.

I built this bot to solve that problem. It serves as a personal assistant that fetches your current bill amount, due date, and payment status directly within Telegram. It leverages Python and web scraping to bridge the gap between complex utility portals and a simple chat interface.

## ⚙️ Tech Stack

* **Core:** Python (3.8+)
* **Interface:** Telegram Bot API
* **Libraries:** `python-telegram-bot`, `Requests`, `BeautifulSoup` (for scraping), `Pandas`
* **Deployment:** Capable of running locally or on cloud instances (AWS/Heroku)

## ✨ Key Features

* **Instant Fetching:** Get bill details by simply entering a Consumer Number.
* **Status Updates:** Check if your last payment was processed.
* **Lightweight:** No need for external apps; works entirely inside Telegram.
* **Secure:** Runs locally with no external data storage.

## 🚀 How to Run

Follow these steps to get the bot running on your machine:

1.  **Clone the Repository**
    ```bash
    git clone [https://github.com/Aniket-Raikwar1/Electricity-Bill-bot.git](https://github.com/Aniket-Raikwar1/Electricity-Bill-bot.git)
    cd Electricity-Bill-bot
    ```

2.  **Install Dependencies**
    ```bash
    pip install -r requirements.txt
    ```

3.  **Configure Tokens**
    * Create a `.env` file in the folder.
    * Add your Bot Token from BotFather: `TELEGRAM_BOT_TOKEN=your_token_here`

4.  **Start the Bot**
    ```bash
    python main.py
    ```
